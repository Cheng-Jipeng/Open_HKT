# Preference supplement: CFL2013

Final publication is **Quantitative Economics**, not JFE; 2012 refers to a working-paper version. See the companion JSON for all four exact Table2 estimates, confidence intervals, quarterly discount factors, original notation, and source locators.

For gamma, the paper supplies consequential contradictory evidence: estimated stockholder risk aversion17/20 and aggregate57.5/60, versus much smaller lifecycle and experimental estimates in the original memo. The span17–60 describes specifications, not a confidence interval. These belong in a distinct high-risk sensitivity family; selecting only values below1 would discard this evidence. Mapping remains qualified because V6 fixes EIS=1 and has terminal old-age consumption, whereas the source estimates infinite-horizon continuation-value risk with free EIS.

The quarterly recursive discount factors do not bypass the original memo's cohort/normalization problem for V6 beta. Their names coincide, their meanings do not.
