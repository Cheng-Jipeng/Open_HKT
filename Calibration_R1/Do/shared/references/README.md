# Shared methodological and data references

These files explain the calibration's empirical inputs and identifying restrictions. They contain research provenance and should be retained with the calibration. They are not generated caches. Read the date and sample inside each audit: some describe the earlier 1994–2022 specification; the curvature-selection note covers the later 2009–2024 exercise.

| File | Role |
| --- | --- |
| [reference_conversation.md](reference_conversation.md) | Saved calibration discussion, including the P1–P5 sequence, normalization and RoW mapping questions; background material rather than executable instructions |
| [reference_audit.md](reference_audit.md) | Audit of the model/plan and external literature: markup, substitution, timing, normalizations and admissibility |
| [rho_selection.md](rho_selection.md) | Rationale for rho=2, supporting source loci and the limitations of the capital–labor analogy |
| [data_audit.md](data_audit.md) | Data columns, source mappings, units, compensation bridge, sector coverage and empirical limitations |
| [data_audit_feasibility.csv](data_audit_feasibility.csv) | Tabulated feasibility evidence associated with the data audit |
| [source_validation.csv](source_validation.csv) | Source-verification ledger and access/verification outcomes |
| [solver_audit.md](solver_audit.md) | Comparison of the calibration equations with the reference model implementation, including timing, units and admissibility checks |

There is one canonical copy of each shared reference here. References to previous locations in preserved historical snapshots describe their original execution context. Current run navigation uses the new paths.
