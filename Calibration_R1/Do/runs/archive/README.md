# Historical calibration records

These records are retained to document earlier specifications and findings. They are not dependencies of the active Run 2 numerical estimation. Deleting them would discard the ability to inspect the earlier work; they have been moved, not deleted.

| Folder | Contents |
| --- | --- |
| [2026-10-12_before_rho2_2009_latest](2026-10-12_before_rho2_2009_latest/README.md) | Code, configuration, inputs and results preceding the rho=2 / 2009–2024 change, including the older 1994–2022 calibration |
| [before_spillover_diagnosis](before_spillover_diagnosis/README.md) | Snapshot before the subsequent spillover diagnosis and reporting updates |
| [P1_Diagnosis_1994_2022](P1_Diagnosis_1994_2022/README.md) | Historical accounting and mapping investigation of P1, with annual decompositions, source log and figures |

Older snapshot code and manifests retain their original paths as historical records. The separately maintained P1 diagnosis's directory constants and rerun instructions have been updated to this location; its data and results are unchanged. Current runs are in `../01_observed_labor` and `../02_fixed_mean_labor`; see [the run index](../../README.md).
